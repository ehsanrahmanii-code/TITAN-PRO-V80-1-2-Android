# TITAN PRO V80.1.2 — Android APK

موتور کامل تحلیل (Central Nervous Seal) داخل APK با Chaquopy.

## ساخت و دانلود APK
1. برو به **Actions**
2. **Build TITAN V80.1.2 APK** را انتخاب کن
3. **Run workflow**
4. بعد از اتمام، Artifact با نام `TITAN-PRO-V80.1.2-APK` را دانلود کن

## محتوا
- کل موتور Python V80.1.2 (اصلاح LONG/SHORT، ماتریس TF، سیستم عصبی واحد)
- Flask روی `127.0.0.1:8080` داخل گوشی
- وابستگی‌ها داخل APK: numpy, pandas, flask, waitress, requests
