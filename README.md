## ساخت و دانلود APK (۳ کلیک)
1. برو به تب **Actions**
2. انتخاب **Build TITAN V80.1.2 APK**
3. **Run workflow** → بعد از اتمام، Artifact به نام `TITAN-PRO-V80.1.2-APK` را دانلود کن

- پروژه کامل اندروید (Chaquopy + WebView)
- موتور از ریپوی `TITAN-V80-Full-Android` دانلود می‌شود
- پچ‌های سیستم عصبی V80.1.2 (LONG/SHORT درست + ماتریس TF) روی موتور اعمال می‌شوند
- سرور Flask داخل گوشی روی `127.0.0.1:8080`
